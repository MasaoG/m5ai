参加前にお願いしたいこと

インターンシップで使うAIを、あらかじめお使いのPCに用意していただきます。

所要 10〜20分（ダウンロード待ち時間を含む）

!なぜ必要か

このハンズオンでは、ブラウザの中で動くAIを使います。クラウドに送るのではなく、お使いのPCの中だけで推論が完結する仕組みです。

そのため、AIのモデル（約4GB）をPCにダウンロードしておく必要があります。当日に全員分をまとめてダウンロードすると、会場のネットワークが持ちません。

自宅や研究室など、時間に余裕があるネットワークで済ませておいてください。

1Google Chrome を用意する

バージョン148以上の Google Chrome が必要です。すでにお使いなら、自動更新で条件を満たしているはずです。

  • デスクトップ版のみ。スマートフォンやタブレットでは動きません
  • Edge、Brave、Opera などは対象外です
  • Linux の方は、ディストリビューション配布の Chromium ではなく公式ビルドの Chrome をお使いください

インストールしたら、このページを Chrome で開き直してから次に進んでください。

2AIを準備する

下のボタンを押すだけです。

ダウンロード中 ページを閉じずにお待ちください。回線速度によって数分〜十数分かかります。

3結果を運営に送る

下のボタンでテキストをコピーし、案内メールに返信して貼り付けてください。当日スムーズに始めるために使います。

?うまくいかないとき

「この端末では利用できません」と出た

AIを動かすには、以下が必要です。

メモリ（RAM）16GB 以上
空きストレージ22GB 以上
CPU4コア以上

満たさない場合でも問題ありません。当日は貸出用のPCをご用意しています。その旨を運営にお知らせください。

ボタンを押しても何も起きない

Chrome 以外のブラウザで開いている可能性があります。アドレスバーに chrome://version と入力して、バージョンが148以上か確認してください。

ダウンロードが途中で止まった

ページを再読み込みして、もう一度「準備を開始する」を押してください。途中まで進んだ分は無駄になりません。

一度成功したのに、また「準備できていない」と出る

Chrome やモデルが更新されると、再ダウンロードが必要になることがあります。もう一度ボタンを押してください。異常ではありません。

解決しない場合は、無理をせずそのまま当日お越しください。会場で対応します。貸出PCもご用意しています。
